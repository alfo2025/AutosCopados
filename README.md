# AutosCopados
Un proyecto html de programación web y móvil

Integrantes:
- Diego Silupu
- Alfonso Ko

Paginas(Funciones):
- Inicio: Ver los autos a la venta en listado con filtros
- Registro: Poder registrarse como usuario a traves de un formulario HTML(formulario) SI
- Publicaciones: Pagina de publicaciones de vendedor(para el mismo vendedor). Botones de ver publicacion, ver propuestas, editar, borrar.
- Pagina donde el vendedor carga: titulo, fotos, caracteristicas, descripcion y precio pedido.
- Pagina de publicacion: Titulo, fotos, caracteristicas, descripcion, chat y precio  SI
- Pagina de propuestas para el vendedor, con el precio ofrecido y una apreciacion del posible comprador. Si se acepta cambia el estado a vendido
